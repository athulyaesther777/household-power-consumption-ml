# 🏠 Household Power Consumption Prediction using Machine Learning

An end-to-end Machine Learning web application that predicts household electricity consumption and cost based on user inputs such as number of days, lights, fans, and other appliances. The system also provides monthly and yearly projections, carbon emission estimates, interactive visualizations, and downloadable energy reports.

---

## 🚀 Project Overview

This project demonstrates a complete Machine Learning workflow:
- Real-world dataset preprocessing
- ML model training
- Feature engineering for appliance-level personalization
- Interactive web application using Streamlit
- Energy analytics with sustainability insights

The goal is to help households understand and optimize their electricity usage while showcasing practical ML and deployment skills.

---

## ✨ Key Features

- 🔮 ML-based energy consumption prediction  
- 💡 Appliance-level personalization (lights, fans, other appliances)  
- 📅 Monthly and yearly energy & cost projections  
- 📊 Interactive energy consumption charts  
- 🌱 Carbon emission estimation (sustainability analysis)  
- 📄 Downloadable household energy report  
- 🌐 Deployable web application using Streamlit  

---

## 🧠 Machine Learning Approach

- Trained using real household power consumption data from Kaggle  
- Regression-based ML model for baseline daily energy estimation  
- Feature engineering to incorporate user-specific appliance usage  
- Model inference integrated directly into a web application
